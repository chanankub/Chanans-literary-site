# החלטות ומגבלות

הרשימות כאן הן החלטות שקל לאבד. חברות של שיר בבלוק, וסדר הבלוקים, אינם ביניהן. אותם משנים בקוד הרשימה, כמתואר ב־[מיקום שיר ברשימה](./03-poetry-index.md).

## למה כך

**הטלפון פתוח בלי כניסה.** קישור הדוא״ל חייב להיפתח בדפדפן שביקש אותו. בטלפון יישום הדואר והדפדפן של האתר אינם אותו דבר באופן שאפשר לסמוך עליו. קוד בן 6 ספרות היה עוקף את זה. הגרסה החינמית של Supabase אינה מאפשרת לערוך את נוסח ההודעה, ולכן המסלול הזה לא הופעל.

**במחשב הטקסט נפתח אחרי כניסה.** הכותרות נשארות גלויות. הגוף, הביקור והתגובות שייכים למי שנכנס. כך אפשר לשמור «מה ראיתי» ולדעת מי כתב.

**כניסה נשארת בדפדפן.** אחרי קישור אחד אין צורך בדוא״ל חוזר באותו דפדפן. «יציאה» נועלת את הביקור ומשאירה את הכניסה השמורה.

**תגובות אינן מוצגות בטלפון.** בלי כניסה אין חשבון לשייך אליו תגובה, ואין מקום בטוח להציג הערות פרטיות.

**בלוק בעל שם אינו מקבץ משוררים תחת כותרות פנימיות.** השירים רצופים. השיר הראשון של משורר נושא שם מלא ושנים, והבאים אחריו שם עברי בלבד. משורר עם כמה שירים מחוץ לבלוק כזה עדיין מקבל כותרת אחת, והשירים תחתיה הם כותרות בלבד.

**הדפסת תרגום נושאת קרדיט. שיר של חנן לא.**

## מגבלות

- טלפון נקבע לפי מצביע גס. חלון צר במחשב אינו טלפון, חוץ מההערה בעמוד הבית. טאבלט ומסך מגע נחשבים טלפון.
- «יציאה» במחשב אחד אינה מוחקת כניסה שנשמרה במחשב אחר.
- קישור ישן, או קישור שנפתח בדפדפן הלא־נכון, נכשל. מבקשים קישור חדש ופותחים אותו שם.
- תגובה פומבית של כל האתר אינה מרוכזת בעמוד אחד.
- שינוי נוסח הודעת הכניסה דורש תוכנית Supabase שמאפשרת עריכת תבנית. עד אז `supabase/templates/magic_link.html` אינו מה שהקורא מקבל.
- `order` ב־frontmatter של שיר אינו משנה את מקומו ברשימת השירה. הוא כן משנה מקום בסיפורים ובהערות שלא נמשכו לבלוק.

## כשמשהו נשבר

| מה רואים | מה לבדוק |
|----------|----------|
| הדפדפן מסרב לחיבור אל שרת הפיתוח | הכתובת היא `127.0.0.1` והפורט שהטרמינל הדפיס, לא `localhost` בפורט ישן |
| שיר או סיפור חסר ברשימה | `draft: false`, והקובץ אינו מתחיל ב־`_`. שיר ששייך לבלוק צריך slug או שם משורר שתואם את הרשימה |
| הבנייה נכשלת על שיר | YAML של `pairs`: מירכאות, ובפריט ריק רק `spacer: true` |
| תמונה שבורה | הנתיב מתחיל ב־`/Chanans-literary-site/images/...`, והקובץ ב־`public/images/` |
| הכניסה מציגה הערת הגדרה | `.env` מקומית, או secrets ב־GitHub, עם שני המפתחות |
| הקישור מהדוא״ל נכשל | לפתוח אותו בדפדפן שביקש אותו. אם פג, לבקש חדש |
| תגובה אינה מופיעה | במחשב, אחרי כניסה. פרטית אינה בריחוף. בטלפון התגובות מוסתרות בכוונה |
| הערות פרטיות ריקות | להיכנס בדוא״ל הבעלים שב־`private.owner`. קורא אחר רואה רשימה ריקה |
| הדחיפה עברה והאתר ישן | ב־Actions, שהריצה הסתיימה. אם Pages לא הוגדר ל־GitHub Actions, הריצה נכשלת ביצירת הפריסה |
| 404 אחרי שינוי שם קובץ | ה־slug השתנה. הפניה, אם צריך, נוספת ב־`redirects` שב־`astro.config.mjs` |
