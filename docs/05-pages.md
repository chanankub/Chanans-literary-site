# איך נבנים הדפים

Astro קורא את האוספים בזמן הבנייה ומפיק HTML סטטי. אחרי שהדף נטען, מעט סקריפטים בדפדפן פותחים את גוף היצירה, שומרים ביקור, ומציגים תגובות. אין שרת משל האתר.

האוספים מוגדרים ב־`src/content/config.ts`: `poems`, `stories`, `notes`, `about`. הסכמה שם היא מה שמותר לכתוב ב־frontmatter. שדה לא מוכר, או `pairs` ריק, מפיל את הבנייה.

## כתובות

`astro.config.mjs` קובע:

- `site`: `https://chanankub.github.io`
- `base`: `/Chanans-literary-site`
- `trailingSlash: always`

קישור פנימי נבנה דרך `withBase` ב־`src/lib/content.ts`, כדי שהבסיס לא יישבר. הפניות קבועות, למשל משמות ישנים של שיר, יושבות ב־`redirects` באותו קובץ.

עמוד של יצירה הוא `src/pages/translations/[slug].astro`, וכך גם לסיפורים ולהערות. slug הוא שם הקובץ בלי `.md`.

## שיר על המסך

`PoemParallel.astro` מצייר את ה־`pairs`.

- עברית בלבד (`sourceLang: he`, או שורות בלי מקור) — עמודה אחת.
- דו־לשוני — מקור מול עברית. במסך רחב שתי העמודות יחד. במסך צר יש מתג: מקור או תרגום.
- תלת־לשוני (`pairLayout: trilingual`) — מקור, אנגלית, עברית, עם מתג.

הדפסה קיימת בעמוד שיר. הכפתור מודד את הגובה: שיר קצר נשאר בעמוד אחד, ושורה בודדת אינה נשארת לבד בראש עמוד. בתחתית הדפסה של תרגום מופיע «תרגום: חנן קוביצקי» והכתובת. בשיר של חנן השורה הזו אינה מודפסת.

## מעטפות

`BaseLayout.astro` עוטף כל עמוד: עברית, RTL, הגופנים, הניווט, ושורת הקורא (כניסה, כינוי, מה ראיתי). `ProseLayout.astro` מוסיף לסיפור ולהערה את גוף הטקסט. העיצוב כולו ב־`src/styles/literary.css`.

עמוד הבית הוא פנייה קצרה, תמונה, השם, וארבעת המדורים. בחלון צר מ־640 פיקסלים מופיעה מתחת לשם בקשה לראות את האתר במחשב.

## סקריפטים שאינם האתר

`npm run import:docx` הוא כלי הייבוא. שאר הקבצים ב־`scripts/` (`fill-english.mjs`, `fill-columns.mjs`, `scots-to-pairs.mjs`) מילאו שיר מסוים מקובצי טקסט. הם אינם חלק מנתיב הפרסום.
