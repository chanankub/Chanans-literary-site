# תיעוד האתר

המדריכים כאן מתארים את האתר. הם אינם תוכן של האתר.

שירי התרגום, הסיפורים, ההערות ועמוד האודות נמצאים ב־`src/content/` ורק הם נבנים לדפים. התיקייה `docs/` אינה אוסף תוכן, אינה דף, ואינה עולה ל־GitHub Pages.

| מדריך | נושא |
|--------|------|
| [מהו האתר](./01-site.md) | מטרה, כתובת, מדורים, ומפת התיקיות |
| [מה רואה הקורא](./02-readers.md) | טלפון מול מחשב, כניסה, תגובות, מה ראיתי |
| [מיקום שיר ברשימה](./03-poetry-index.md) | איך מרכיבים את רשימת שירה ותרגומים |
| [הוספת יצירה](./04-authoring.md) | שיר, סיפור, הערה, אודות, Obsidian, Word |
| [איך נבנים הדפים](./05-pages.md) | אוספים, תבניות, שיר מקביל, הדפסה |
| [חשבונות ותגובות](./06-accounts.md) | Supabase, טבלאות, מי רשאי לקרוא |
| [הרצה ופרסום](./07-running.md) | שרת מקומי, סודות, GitHub Pages |
| [החלטות ומגבלות](./08-decisions.md) | למה האתר מתנהג כך, ומה לבדוק כשמשהו נשבר |

המדריכים הישנים בשורש המאגר — `AUTHORING.md`, `OBSIDIAN.md`, `DEPLOY.md`, ו־`reader-login/README.md` — מפנים לכאן.
